# frontend - https://twohoursonelife.com

Refer to README.md for tech details and building.

Refer to these instructions for avoiding mistakes when working here:
- Styling
  - Use Tailwind canonical classes
  - Generalise styling when possible so that it can be reused as Nuxt intends
    - Avoid hard coded styling hacks
    - Never duplicate styling already set by `app.config.ts`
  - Do not use the brand colour, primary is preferred.
- Do not insert unnecessary sectional comments
- Do not run a build or generate after each iteration
  - It takes too long, instead use it sparingly according to your judgement
- Always read a file before writing to it, ensure to preserve any edits made by
  the user.
